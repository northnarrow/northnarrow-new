| 4 | `watchdog-respawn-1` | **Beta** | fixed (respawn v2) | `watchdog/src/main.rs:104`, `deploy/systemd/northnarrow-watchdog.service` | With `--agent-bin` the respawn argv is `[bin, --pid-file]` only (drops `--combat-rules`, `--admin-pub`, `--admin-socket`, `--detect-only`); the agent is re-exec'd as a CHILD of the watchdog unit, i.e. inside `MemoryMax=64M`, `TasksMax=8`, `CapabilityBoundingSet=CAP_BPF CAP_SYS_ADMIN`, `ProtectHome=true`. `BindsTo=northnarrow-agent.service` also stops the watchdog when the agent unit goes inactive. Fixed per `docs/design/WATCHDOG_RESPAWN_V2_DESIGN.md`: the watchdog respawns with `systemctl start --no-block northnarrow-agent.service` (own unit, own argv/caps/cgroup), `BindsTo=` removed, `StartLimitIntervalSec=0` on the agent unit; the `exec` backend (non-systemd) now captures the full argv from `/proc/<pid>/cmdline`. Supersedes `combat-avail-1`. *VM:* `kill -9 <agent>` → `systemctl is-active northnarrow-agent` = active, new PID's `CapEff` includes CAP_KILL, cgroup is the agent unit's. |
